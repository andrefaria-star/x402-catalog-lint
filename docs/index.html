x402 Catalog Verifier

Paste an x402-style agent commerce catalog URL. This page runs the same six executable trust checks as the x402-catalog-lint CLI — no install needed.

Checks: USDC currency · well-formed seller address · non-empty resources · resource ids · priced or freePreview · identityCard linkage.
Note: browsers enforce CORS — stores that don't send CORS headers can't be checked from here. Use the CLI (npx github:andrefaria-star/x402-catalog-lint <url>) for full access, or bin/onboard.js for end-to-end buyer onboarding with payment instructions.
